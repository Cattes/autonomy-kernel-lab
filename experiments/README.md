# Experiments

Throwaway Mojo programs that are not part of the `autonomy` stack: the
official GPU tutorial (`01_vector_add.mojo`), puzzle variations, API probes
when a Mojo release changes something.

Run one with:

```bash
pixi run mojo run -I . experiments/01_vector_add.mojo
```

They are not run in CI. Anything worth keeping moves into `autonomy/` with
tests.
